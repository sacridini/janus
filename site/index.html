Raster time series viewer · Windows · macOS · Linux

Look back.
Look ahead.

Janus opens a folder of rasters as a data cube, keeps the whole cube on the GPU and shows the series of any pixel as you move the mouse. It is built to explore time series quickly, not to be a full GIS.

Download View on GitHub
jn D:\data\ndvi_annual\
jn ~/data/landsat_stack.tif
jn "S2_*_NDVI.tif" --band 1

After installing, jn opens the window and gives the prompt back right away.

How it works

Every pixel has a past.

Each date is one layer of the cube. Janus keeps a reduced copy of all of them in GPU memory, computes the per-pixel statistics in a shader and, while the mouse rests, reads the full-resolution series of that pixel from disk in the background.

from launch to the first frame
0.3 ms

Features

Made for looking at time.

Open

Any stack of rasters

A folder (one file per date), a multiband file (one band per date), a list of files or a wildcard. Dates are read from file names or band descriptions.

YYYY-MM-DD · YYYYMMDD · YYYY_MM · YYYY · A2001001

Map

Statistics on the GPU

Value at date, anomaly, mean, standard deviation, linear trend, minimum, maximum, amplitude, trend R² and a multitemporal RGB. Changing the date, colormap or stretch is instant.

13 map modes · animation player

Series

Hover, pin, compare

An approximate series appears as soon as you hover and the exact one once the mouse rests. Click to drop pins; Shift+drag for a region with its mean and p10–p90 band.

OLS and Sen trend · anomaly · z-score

Classes

Categorical series

Land cover and classification stacks are detected from colour tables or category names. The chart shows the class sequence and the table reports the last change.

e.g. 2006: Forest → Pasture

Bands

Several bands per date

Show any band of a Landsat or Sentinel stack, or a normalized difference of two, and hide cloudy observations with a quality band.

NDVI · NDMI · NBR · Fmask · QA_PIXEL

Layers

Side by side

Open several series as layers placed by their georeferencing, and show them in map panels that pan and zoom together, each at its own date and mode. Drag any panel to a second monitor.

Ctrl+T / Ctrl+W · 2005 next to 2020 · NDVI next to NBR

Detail

Full resolution on zoom

Past the overview resolution, tiles of the visible area are read in the background and cached on the GPU. The overview is cached on disk date by date, so reopening takes a fraction of a second and closing during the first open loses nothing.

COG-friendly · HDD-aware reader

Change

Difference and largest drop

Map the difference from a reference date, or from the previous one, on a diverging scale. Or map when the largest drop happened and how deep it was, computed for every pixel on the GPU.

Δ to a date or t−1 · drop date · drop magnitude

Compare

Swipe

Drag a divider across the map to compare it with another layer, or with the same layer at another date or in another mode.

S to toggle · 1985 | 2025 · NDVI | NBR

Space-time

Transect

Draw a line on the map and see distance against time in one image: deforestation fronts and regrowth appear as shapes. Hover marks the place on the map, a click goes to that date.

Ctrl+drag · values or anomalies · CSV

Export

Out to your tools

Save the map as a PNG for figures, at up to 4× the screen resolution, with legend and date. Save the values or the rendered view as a georeferenced GeoTIFF for QGIS, and the series as CSV.

PNG · GeoTIFF · Zeit results · CSV

Analysis

Change detection

Breaks, trends and seasons, built in.

The Zeit algorithms are fitted live on the cursor, pins and region, or run on the whole image, the visible area or a region, with the results added as map layers. Zeit runs in a private Python runtime that ships with Janus, so there is nothing else to install.

  • LandTrendr

    Year of detection, magnitude, duration and rate of the chosen loss or gain event.

    annual series

  • Mann-Kendall

    Significant Sen's slope, p-value and trend class, with Hamed-Rao, Yue-Wang and seasonal variants.

    any series

  • BFAST

    Trend and season break counts, date and magnitude of the largest break.

    ≥ 2 dates per year

  • BFAST Lite

    Break count, date and magnitude of the largest break, first break date.

    ≥ 2 dates per year

  • BFAST Monitor

    First break in the monitoring period, its magnitude, break yes or no.

    ≥ 2 dates per year

  • Phenology

    Start, peak and end of season, length, amplitude, for a typical year or a chosen one.

    ≥ 6 dates per year

  • CCDC

    Break count, largest break, NDVI change and segments from every reflectance band.

    one file per date, multiband

  • TWDTW

    A class map from patterns you take from pins on places you know.

    classification

  • Smoothing

    Whittaker and Savitzky-Golay, drawn over the series on the chart.

    chart only

Install · latest release

Nothing else to install.

Each package carries GDAL, the PROJ and GDAL data and the Python runtime with Zeit. No Python or conda needed, and nothing is added to your Python installations.

Windows

Run the installer. It installs per user, without an administrator prompt, and can add jn to PATH, an Open in Janus entry to the right-click menu of folders and .tif files, and a desktop shortcut.

Download .exe

janus-<version>-setup.exe

macOS Apple Silicon

Open the disk image and drag Janus into Applications. The app is not signed with an Apple Developer ID: the first time, open it with right click → Open. To call it from a terminal, link it once:

ln -s /Applications/Janus.app/Contents/MacOS/janus ~/.local/bin/jn
Download .dmg

janus-<version>-macos-arm64.dmg · macOS 15 or later

Linux x86_64

Extract the archive anywhere and run jn from that folder. It is portable: only glibc, OpenGL and X11 come from the system. janus.desktop is included for a menu entry.

Download .tar.xz

janus-<version>-linux-x86_64.tar.xz · tested on Ubuntu 24.04

Prefer to build it yourself? Building from source needs CMake, a C++17 compiler and GDAL.

Command line

One command, any series.

The command line only opens and shows. Bands, indices, cloud masks and the Zeit tools live in the interface.

Terminal
# every raster in the folder, 1 file = 1 date
jn D:\data\ndvi_annual\

# 1 multiband file, 1 band = 1 date
jn landsat_stack.tif

# a wildcard pattern, band 1 of each file
jn "S2_*_NDVI.tif" --band 1

# options
--band N        band used when each file is one date
--budget MB     memory for the cube overview (default 1024)
--threads N     background reader threads (HDD = 1)

Questions

Before you open a cube.

Is Janus a GIS?

No. It is a viewer for exploring time series quickly: open, move through time, inspect any pixel and run change and trend analyses. For editing vectors, reprojecting or making maps, keep using your GIS.

Which files can it open?

Anything GDAL reads, as a folder of rasters (one date per file), a multiband file (one date per band), a list of files or a wildcard pattern. Cloud-optimized GeoTIFFs open fastest the first time.

Do I need Python for the Zeit tools?

No. Zeit runs in a private, invisible Python runtime inside the installation. It starts in the background after a series opens, so it never slows the startup.

Will a spinning hard disk be slow?

Janus detects spinning disks and reads them with a single sequential reader, which was measured to be four times faster than two. The first open is bound by the disk; after that the cube comes from the overview cache. The cache is written date by date, so if you close Janus halfway, the next open reads only the dates still missing.

Why the name?

Janus is the Roman god of doorways and of time, shown with two faces: one looks at the past and one at what comes next. That is what you do with a pixel's series. Up to version 0.16 the program was called tsv.

Built in C++17 with Dear ImGui, ImPlot and GDAL. OpenGL on Windows and Linux, Metal on macOS.
